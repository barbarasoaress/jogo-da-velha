# 🎮 Jogo da Velha

Jogo da Velha desenvolvido com **HTML, CSS e JavaScript**, com partidas entre a pessoa jogadora e o computador.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Jogador utiliza **X**
- Computador realiza jogadas automáticas com **O**
- Verificação das combinações de vitória
- Detecção de empate
- Destaque visual da combinação vencedora
- Botão para reiniciar a partida

## 🌐 Projeto online

👉 [Jogar agora](https://barbarasoaress.github.io/jogo-da-velha/)

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar lógica de programação, eventos, manipulação do DOM, arrays e controle do estado de uma aplicação com JavaScript.
